GDScript 参考

GDScript 是 Godot 引擎的高层、面向对象、命令式、渐进式类型编程语言，基于 Python 式的缩进语法。它的目标是与 Godot 引擎深度集成，为内容创建和整合提供最大灵活性。GDScript 完全独立于 Python，不基于它。

标识符

任何由字母（a-z, A-Z）、数字（0-9）和下划线（_）组成的字符串都是标识符。标识符不能以数字开头。标识符区分大小写（foo 与 FOO 不同）。

变量

GDScript 是动态类型语言，但支持可选类型标注：

var a                        # 动态类型
var b := 10                  # 自动推断为 int
var c: int = 10              # 显式类型
var d: String = "text"
var e: Array[int] = [1,2,3]
var f: Dictionary = {"k": "v"}

# 带 setter/getter 的属性
var health: int = 100:
    get:
        return health
    set(value):
        health = clamp(value, 0, 100)

控制流

# if / elif / else
if score >= 100:
    print("通关！")
elif score >= 50:
    print("继续努力")
else:
    print("加油")

# match 模式匹配
match command:
    "attack":
        attack()
    0:
        print("数字零")
    var something:
        print("其他值: ", something)
    _:
        print("默认分支")

# for 循环

    print(i)

for item in inventory:
    print(item)

for key in dict:
    print(key, dict[key])

# while 循环

while count < 10:
    count += 1

信号

# 声明信号
signal health_changed(new_value)
signal died

# 发射信号
func take_damage(amount):
    health -= amount
    health_changed.emit(health)

# 连接信号
func _ready():
    health_changed.connect(_on_health_changed)
    health_changed.connect(_on_health_changed.bind(&"extra参数"))

func _on_health_changed(new_value):
    print("血量为: ", new_value)

生命周期回调（虚函数）

回调说明
_init()对象初始化（构造函数）
_ready()节点进入场景树后调用
_process(delta)每帧调用，delta 为帧时间
_physics_process(delta)物理帧调用（默认 60Hz）
_input(event)收到输入事件时
_unhandled_input(event)未处理的输入事件
_exit_tree()节点离开场景树
_enter_tree()节点进入场景树时（先于 _ready）
